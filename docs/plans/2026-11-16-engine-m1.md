# Workspace engine M1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A developer declares projects (sessions, windows, split panes, commands) in TOML, and `cairn up` / `cairn open <project>` creates exactly that in tmux — the same way after a reboot, a crash or a dead battery — with `plan`, `apply`, `capture`, `status` and `undo`, usable next to an existing tmux setup.

**Architecture:** Pure packages (`workspace` config + layout math, `reconcile` diffing) sit on a thin `tmux` driver that only shells out through `execx.Runner`. State is observed by polling `list-*` (stateless, resync-safe), objects are matched by `@cairn_*` user options (never names), commands are started as argv (never `send-keys`), layouts are applied as exact tmux layout strings. Config changes are recorded in an append-only history with file snapshots so they can be undone.

**Tech Stack:** Go (existing module `github.com/mrqwer/cairn`), tmux ≥ 3.2 (developed on 3.8), `github.com/pelletier/go-toml/v2` (already a dependency), existing `internal/{fsx,execx,xdg,plan,ui,doctor,config}`; tests use real tmux on an isolated socket (`tmux -L cairn-test-<pid>`), skipped when tmux is absent.

**Spec:** `docs/specs/engine-agents.md` §3a, §4, §5, §7, §8, §10, R1–R10 (this plan is milestone M1). Principles: `docs/principles.md`.

## Global Constraints

- Public repo: no author-specific names, paths or project names in code, docs, fixtures or tests (fixtures use `/home/u/...`, project ids like `demo`, `web`, `api`).
- XDG paths via `xdg.Dirs`: workspace config in `<Dirs.Config>/projects/<id>.toml`; history in `<Dirs.State>/history.jsonl`; no hardcoded user paths.
- tmux is driven only through `execx.Runner` (`tmux [-L <socket>] ...`); tests use `execx.FakeRunner` for argument checks and a real isolated tmux server for behaviour. The tool never touches a tmux server it was not pointed at; the default socket is used unless `--socket <name>` / `CAIRN_TMUX_SOCKET` is given (so people can try it beside their own sessions).
- Never kill, rename or resize anything not carrying a `@cairn_s` session marker. Unmanaged sessions are invisible to apply, `--prune` and undo.
- Matching uses ids and user options: `@cairn_s` = project id (session), `@cairn_w` = `<project>/<window key>` (window), `@cairn_p` = `<project>/<window key>/<n>` (pane, n = 1-based position in config). Distinct option names are mandatory (tmux format lookup falls back pane→window→session). Targets in commands are tmux ids (`$1`, `@2`, `%3`) captured with `-P -F`, never names or indexes.
- Pane commands run as argv: `new-window/split-window ... -- <argv...>`; a single-element `run` is passed as one shell string. Panes with a command get `remain-on-exit on` so a crashed program leaves a dead pane that `apply` can restart.
- Window and session names set explicitly with `-n` and `automatic-rename off`.
- Layout strings are the classic form `<csum>,WxH,X,Y{...}` / `[...]`; checksum `c=0; for ch in body: c=((c>>1)+((c&1)<<15)+ord(ch))&0xffff`, printed `%04x`. (tmux 3.8 prints layouts as JSON for normal clients; the tool never parses layouts, it only generates them and reads pane geometry from `#{pane_left}` `#{pane_top}` `#{pane_width}` `#{pane_height}`.)
- Output for terminals uses `internal/ui` styling; pipes get plain text. `--json` on `status` and `plan`.
- Deviation from spec §5 (ruling): history is an append-only JSONL file with file snapshots in M1 (principle 4 holds); SQLite arrives with the search index (M4). Undo reverts config only; `cairn apply` re-applies.
- Commit messages describe the change only — no AI attribution. Do not push.

## Review Focus

1. **Second `apply` on an unchanged workspace** changes nothing and prints `nothing to do` — Task 5.
2. **A managed pane whose program died** is restarted by `apply`; one running a program is never killed by apply or prune — Task 5.
3. **A project root that does not exist** (unmounted disk, typo) is reported per project; other projects still apply — Task 6.
4. **Commands with spaces, quotes, `$` and unicode** reach the program unchanged — Task 3.
5. **`cairn` run inside a tmux session** (TMUX/TMUX_PANE set) must not target the surrounding session implicitly and `open` must switch the client instead of nesting — Task 3 and Task 6.

### Task 2: Layout math — split sequence → tree → geometry → tmux layout string

**Files:**
- Create: `internal/workspace/layout/tree.go`, `geometry.go`, `tmuxstr.go`
- Test: `internal/workspace/layout/layout_test.go`

**Interfaces:**
- Consumes: `workspace.Pane` (Split, From, Size).
- Produces:
  - `type layout.Node struct{ Leaf int; Split string; Ratio int; A, B *layout.Node }` — a leaf has `Split == ""` and `Leaf` = 1-based pane position; a split has `Split` `h`/`v` and `Ratio` = percent of the area given to `B` (the new pane), children `A` (existing) and `B`.
  - `func layout.Build(panes []workspace.Pane) (*layout.Node, error)` — start with leaf 1; for each later pane i, replace the leaf `From` (default i-1) by `Node{Split, Ratio: Size, A: oldLeaf, B: Leaf(i)}`; error on invalid `From`/`Split`.
  - `type layout.Rect struct{ Pane, X, Y, W, H int }` and `func layout.Geometry(n *layout.Node, w, h int) []layout.Rect` — leaves in pane-position order. Split arithmetic (one border cell between siblings): for `h`: `total = w - 1`, `wB = max(1, total*Ratio/100)`, `wA = total - wB`, A at x, B at `x + wA + 1`; `v` the same on height.
  - `func layout.TmuxString(n *layout.Node, w, h int) (string, error)` — classic string `<csum>,<body>` where body is `WxH,X,Y,<n>` for a leaf (n = pane position − 1) or `WxH,X,Y{a,b}` (`h`) / `WxH,X,Y[a,b]` (`v`), children flattened (a split whose child is a split of the same direction stays nested as tmux prints it: nesting by tree, not flattened across levels).
  - `func layout.Checksum(body string) string` — the Global Constraints algorithm.
  - `func layout.Order(n *layout.Node) []int` — leaf pane positions in traversal (in-order, A before B) order = the order the window's panes must have in tmux before `select-layout` (tmux ignores the leaf numbers in the string and assigns existing panes to cells in traversal order; panes are identified by tmux id / `@cairn_p`, never by index). `func layout.Check(n *layout.Node, w, h int) error` (every leaf ≥ 1x1); `TmuxString` returns `(string, error)` and fails when `Check` fails.
  - `func layout.FromRects(rs []layout.Rect, w, h int) (*layout.Node, error)` — inverse used by capture: recursively cut the area by a full-height gap column (`h`) or full-width gap row (`v`) between panes (1 cell border); prefer the cut that splits the area into the fewest panes first; error `layout: no clean split` when none exists.

### Task 3: tmux driver — snapshot, operations, idle check

**Files:**
- Create: `internal/tmux/client.go`, `snapshot.go`, `ops.go`, `idle.go`
- Test: `internal/tmux/snapshot_test.go`, `ops_test.go`, `idle_test.go`, `integration_test.go`

**Interfaces:**
- Consumes: `execx.Runner`, `layout.TmuxString`.
- Produces:
  - `type tmux.Client struct{ R execx.Runner; Socket string }`; every call runs `tmux [-L <Socket>] <args>` with the environment variables `TMUX` and `TMUX_PANE` removed (pass through `execx` env handling — add an `Env` option to `execx.OSRunner` if missing: `OSRunner{Env []string}`; FakeRunner records args only).
  - `type tmux.Pane struct{ ID, Key string; Index, PID, Left, Top, W, H int; Dead bool; DeadStatus int; Cwd, Cmd string }`, `type tmux.Window struct{ ID, Key, Name string; Index, W, H int; Panes []tmux.Pane }`, `type tmux.Session struct{ ID, Name, Key string; Attached int; Windows []tmux.Window }`, `type tmux.Snapshot struct{ Sessions []tmux.Session }`.
  - `func (c tmux.Client) Snapshot(ctx context.Context) (tmux.Snapshot, error)` — three calls with tab-separated `-F` formats: `list-sessions -F '#{session_id}\t#{session_name}\t#{@cairn_s}\t#{session_attached}'`, `list-windows -a -F '#{session_id}\t#{window_id}\t#{window_index}\t#{window_name}\t#{@cairn_w}\t#{window_width}\t#{window_height}'`, `list-panes -a -F '#{window_id}\t#{pane_id}\t#{pane_index}\t#{@cairn_p}\t#{pane_pid}\t#{pane_left}\t#{pane_top}\t#{pane_width}\t#{pane_height}\t#{pane_dead}\t#{pane_dead_status}\t#{pane_current_path}\t#{pane_current_command}'`. No server running (`no server running`, `error connecting`) → empty snapshot, nil error. Because tmux falls back `#{@x}` from pane to window to session, treat a pane key as valid only if it contains two `/` and a window key only if it contains one (otherwise empty).
  - Operations (each returns the new tmux ids parsed from `-P -F`; all targets are tmux ids): `NewSession(ctx, name string, w, h int, win tmux.WindowSpec) (sessionID, windowID, paneID string, err error)` (`new-session -d -P -F '#{session_id} #{window_id} #{pane_id}' -s name -x w -y h -n win.Name -c win.Cwd -e K=V... [-- argv]`; then `set -t <sid> @cairn_s <key>`, window and pane options, `set -w -t <wid> automatic-rename off`); `NewWindow(ctx, sessionID string, win tmux.WindowSpec) (windowID, paneID string, err error)`; `SplitPane(ctx, targetPane string, dir string, percent int, p tmux.PaneSpec) (paneID string, err error)` (`split-window -d -P -F '#{pane_id}' -t <pane> -h|-v -l <percent>% -c <cwd> [-- argv]`, `h` → `-h`, `v` → `-v`); `SelectLayout(ctx, windowID, layoutString string) error`; `SetOption(ctx, scope, target, name, value string) error` (scope `session|window|pane` → `-t`, `-w -t`, `-p -t`); `RespawnPane(ctx, paneID string, argv []string) error` (`respawn-pane -k -t <pane> [-- argv]`); `SwapPanes(ctx, paneA, paneB string) error` (`swap-pane -d -s <a> -t <b>`: swaps the two panes' positions in the window's pane list; ids stay with their processes — verify in the integration test); `KillWindow(ctx, id string) error`; `KillPane(ctx, id string) error`; `KillSession(ctx, id string) error`; `SwitchClient(ctx, sessionName string) error`; `Attach(ctx, sessionName string) error` (not via Runner: `syscall.Exec`-style helper `tmux.AttachCommand(socket, session string) []string` returns argv, the CLI execs it).
  - `type tmux.PaneSpec struct{ Key, Cwd string; Argv []string; Env map[string]string; RemainOnExit bool }`, `type tmux.WindowSpec struct{ Key, Name string; PaneSpec tmux.PaneSpec }`. Env pairs are emitted sorted. Panes with `Argv` get `set -p -t <pane> remain-on-exit on` right after creation. Argv of length 1 is passed as a single shell string; longer argv after `--` as separate arguments.
  - `func (c tmux.Client) PaneIdle(pid int) (bool, error)` — reads `/proc/<pid>/stat`: parse after the last `)`, field 5 = pgrp, field 8 = tpgid; idle ⇔ `tpgid == pgrp` and `/proc/<pid>/task/<pid>/children` is empty; a missing process counts as idle. Reads through an injectable `procFS func(path string) ([]byte, error)` (default `os.ReadFile`).

  - `func history.Diff(c history.FileChange) string` — unified-style `+`/`-` lines (small, line-based) for `cairn history show`.

### Task 5: Reconciler — desired vs observed → operations → apply

**Files:**
- Create: `internal/reconcile/desired.go`, `diff.go`, `apply.go`
- Test: `internal/reconcile/diff_test.go`, `apply_test.go` (fake driver), `integration_test.go` (real tmux, isolated socket)

**Interfaces:**
- Consumes: `workspace.Project`, `tmux.Snapshot`, `tmux.Client` (through the small interface below), `layout`.
- Produces:
  - `type reconcile.Driver interface` with exactly these methods (plus `SwapPanes(ctx context.Context, paneA, paneB string) error`) (the signatures of `tmux.Client` from Task 3, so `tmux.Client` satisfies it; tests use a recording fake):
    `Snapshot(ctx context.Context) (tmux.Snapshot, error)`;
    `NewSession(ctx context.Context, name string, w, h int, win tmux.WindowSpec) (sessionID, windowID, paneID string, err error)`;
    `NewWindow(ctx context.Context, sessionID string, win tmux.WindowSpec) (windowID, paneID string, err error)`;
    `SplitPane(ctx context.Context, targetPane, dir string, percent int, p tmux.PaneSpec) (paneID string, err error)`;
    `SelectLayout(ctx context.Context, windowID, layoutString string) error`;
    `SetOption(ctx context.Context, scope, target, name, value string) error`;
    `RespawnPane(ctx context.Context, paneID string, argv []string) error`;
    `KillWindow(ctx context.Context, id string) error`;
    `KillPane(ctx context.Context, id string) error`;
    `PaneIdle(pid int) (bool, error)`.
  - `type reconcile.Op struct{ Kind, Project, Target, Detail string; Destructive bool }` with `Kind` ∈ `create-session|create-window|create-pane|set-layout|respawn-pane|kill-window|kill-pane|report-extra|report-dead|skip-missing-root`.
  - `func reconcile.Desired(p workspace.Project, size layout.Size, rootExists func(string) bool) reconcile.DesiredProject` — per window: `Spec`, pane list with computed cwd/argv/restart, the layout tree and the tmux layout string for the window size (200x50 for new detached windows, or the existing window's size).
  - `func reconcile.Plan(ps []workspace.Project, snap tmux.Snapshot, opts reconcile.Options) []reconcile.Op` — `Options{Prune bool; Only string; RootExists func(string) bool}`. Rules, in order per project: skip non-`active` projects; if the root directory is missing emit `skip-missing-root` and no further ops for that project (Review Focus 3); missing session → `create-session` (+ its windows/panes/layout as part of it); existing session (matched by `@cairn_s`): per window by `@cairn_w` — missing → `create-window`; existing window: per pane by `@cairn_p` — missing → `create-pane` then `set-layout`; dead managed pane whose config `restart` is `on-failure` (non-zero status) or `always` → `respawn-pane`; dead pane otherwise → `report-dead`; managed windows/panes present in tmux but absent from config → `report-extra` (and `kill-pane`/`kill-window` with `Destructive: true` only when `Prune` is set **and** `PaneIdle` is true for every pane involved; a non-idle pane stays `report-extra`). Matching is by markers only; a window/pane in a managed session without any marker is ignored entirely (user's own additions). Geometry drift is never an op in M1.
  - `func reconcile.Apply(ctx context.Context, d reconcile.Driver, ps []workspace.Project, ops []reconcile.Op) []reconcile.Result` (`Result{Op reconcile.Op; Err error}`) — executes in order, stops a project's remaining ops after its first error but continues with other projects; after any `create-pane` in an existing window runs `set-layout` with the string computed for that window's current size; sets the markers (`@cairn_s/@cairn_w/@cairn_p`) on everything it creates; **before every `set-layout` it makes the window's managed pane list order (by `pane_index`) equal `layout.Order(tree)` mapped to pane keys, using `SwapPanes` (selection sort, at most n−1 swaps)** — a pane re-created by splitting its `From` pane is inserted right after that pane, which can differ from traversal order when a pane in the middle was missing; applies `remain-on-exit on` to panes with a command.
